# One Line, One Idea — a pitch for a friend who has never coded

Built for the [make.fun "A Day of One-Line Pitches" bounty](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3) — a single sentence that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun. Join make.fun with referral code `qgn48q27`: https://make.fun/r/qgn48q27

The program writes that one sentence to `/output/entry.txt` (1–240 characters, one sentence, no code, no explanation). It is the whole entry.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

No build step, no network — plain Node 22 standard library only.
